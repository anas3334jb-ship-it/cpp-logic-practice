# C++ Core Fundamentals & Logic Building

This repository contains my foundational C++ scripts focused on algorithmic logic, loop structures, and array manipulations.

### 📌 Topics Covered
- **Array Operations:** Finding element indexes, basic linear search.
- **Control Flow:** Loops (for, while) and conditional logic patterns.
- **System Logic:** Understanding execution flow at the memory level.

### 🛠️ How to Run
Compile any script using a C++ compiler (g++):
`g++ array_search.cpp -o output`
`./output`
